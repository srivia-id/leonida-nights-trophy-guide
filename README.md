LEONIDA NIGHTS — an offline GTA VI trophy guide and tracker. All 55 PlayStation trophies with cited step-by-step guides (187 sourced steps), a platinum roadmap in stages S1–S7, a missables watch list, and a source matrix. Progress is saved in the browser (localStorage) and can be exported and imported as JSON. The app is static files under app/ and works fully offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```
