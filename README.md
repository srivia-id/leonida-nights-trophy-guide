LEONIDA NIGHTS — a complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with its sources cited beside it, a platinum roadmap in seven stages (S1–S7), a missables watch list led by the one possibly missable trophy, a source matrix, and a progress tracker with localStorage saving, Export/Import JSON, filters and a spoiler setting. No online trophies, no network use: the app is static files that work with the network off.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve the guide locally with `node serve.ts`, then open http://localhost:8080.
